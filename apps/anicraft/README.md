## What is different here

The same code as the original v0.2.1, only without the Discord and social media buttons. Links to GitHub, error reports and updates point to this repository, website links to this fork's website. Everything is built automatically from every new original release ([how it works](../../README.md#how-it-works)).

The easiest way to install it is the [ArtCraft Launcher](../artcraft-launcher/README.md).

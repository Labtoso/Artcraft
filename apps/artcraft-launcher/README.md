# ArtCraft Launcher

**Installs, updates and starts every Craft app.** One window for all apps: shows what is installed, downloads the right build for your computer with one click and keeps everything up to date. This build installs the apps from this repository, so without community links.

## What is different here

The same code as the original v0.10.0, only without the Discord and social media buttons. Links to GitHub, error reports and updates point to this repository, website links to this fork's website. Everything is built automatically from every new original release ([how it works](../../README.md#how-it-works)).

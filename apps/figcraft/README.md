## Was hier anders ist

Gleicher Code wie das Original v0.12.1, nur ohne Discord- und Social-Media-Buttons. Links zu GitHub, Fehlermeldungen und Updates zeigen auf dieses Repo, die Website auf die gespiegelte Seite. Alles wird automatisch aus jedem neuen Original-Release gebaut ([so funktioniert es](../../README.md#so-funktioniert-es)).

Am einfachsten installierst du sie über den [ArtCraft Launcher](../artcraft-launcher/README.md).

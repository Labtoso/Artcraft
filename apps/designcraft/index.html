07DesignCraft

Page layout and publishing, rebuilt in pure Rust.

Spreads and parent pages, threaded stories, styles, swatches and text wrap in a native layout app with a professional paragraph composer. No subscription, no licence server, no telemetry.

02/Highlights

Page layout & publishing

What's inside.

  1. 01

    The layout tools you know

    Spreads and parent pages, frames and threaded stories, paragraph and character styles, swatches and text wrap, laid out the way you expect.

  2. 02

    Beautiful type

    A Knuth–Plass paragraph composer, dictionary hyphenation, optical margin alignment and baseline grids. Line breaks match on screen and in PDF.

  3. 03

    Print-ready PDF

    Real selectable text with embedded fonts, CMYK and spot colors, bleed, crop marks and archival PDF/A output.

  4. 04

    Fast

    Multithreaded SIMD rendering, copy-on-write documents with instant undo, and cached composition.

  5. 05

    Open formats

    A documented native format, PNG export, and layout interchange import and export for moving work between tools.

  6. 06

    Agent-native

    Every menu item, tool, panel and dialog can be driven over a JSON control channel and an MCP server.
